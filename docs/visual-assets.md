# Visual Assets

The work-experience logos are unmodified 200px company marks from the public LinkedIn pages supplied by Shreevikas, downloaded on October 5, 2026 and served locally.

- [NeuralSeek](https://www.linkedin.com/company/neuralseek/posts/?feedView=all): `public/images/experience/neuralseek.jpg`.
- [Whiterock](https://www.linkedin.com/company/whiterocktechnologies/): `public/images/experience/whiterock.jpg`.

Company names and marks belong to their respective owners. Their use identifies professional experience; it does not imply endorsement.

The hero brain is an original, procedural Three.js illustration. Its cortical folds and animated neural pathways are conceptual visuals, not an anatomical scan, measured neural activity, or a research result. It uses instanced nodes/signals, shared line geometry, demand rendering, bounded device pixel ratio, and mobile-specific frame rates. `public/images/neural-brain.webp` is an optimized still render of the same model, shown during loading, for reduced-motion preferences, or when WebGL is unavailable.

Run `npm run test:visuals` to check mesh bounds, outward-facing normals, finite geometry, and neural-path counts. Browser verification also covers image loading, link targets, moving/nonblank canvas pixels, and overflow at phone/tablet/desktop widths.
